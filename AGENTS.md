# Design & Engineering Standards for Raguram's Portfolio

- **Theme & Aesthetic**: Dark cinematic futuristic, high-contrast, atmospheric WebGL depth.
- **Visual Identity**: Aceternity UI CloudShader as the primary signature background in `Hero.tsx`.
- **Layout Architecture**: Editorial asymmetric grids, rich typography with Space Grotesk and Inter, zero generic dashboard templates.
- **Interactivity**: Lenis smooth scroll, spring-physics custom cursor, magnetic button interactions, interactive project modal inspector.
- **Integrity**: Grounded in real student data (CSE 2024–2028 at Sri Krishna College of Engineering and Technology, genuine project FARVISION, real hackathon milestones with Shadow Storm).
